## Creating the OG Image

### Option 1: Quick Canva Creation
1. Go to https://canva.com
2. Create image: 1200 x 630 pixels
3. Design should include:
   - "FabricPrep" logo/text
   - "Microsoft Fabric & Azure Certification Practice"
   - "208+ Practice Questions"
   - Clean, professional design
4. Download as PNG
5. Upload to `/public/og-image.png`
